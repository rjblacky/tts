🎙️ Make voice previews

Run this once. It records a short “Hi, I'm …” sample for every voice, so the website can play previews instantly later.

  1. Click Create all previews and wait (a few minutes the first time; it downloads the ~90 MB voice engine once).
  2. Click Download previews.zip and unzip it inside your repo folder. The files land in audio/previews/.
  3. Upload / commit the audio folder to GitHub. Done.
